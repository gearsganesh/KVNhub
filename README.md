# KVN Group Corporate Website

Corporate/investor-facing hub for KVN Group built around:

**PEOPLE · PLACES · POSSIBILITIES**

Current operating businesses represented:
- Varadaraja Cinemas
- KVN Weddings & Conventions

The portfolio section includes live website previews and direct links to each business.

## Local development

Use one permanent project folder, for example:

`C:\PROJECTS\kvnhospitality`

Install dependencies once:

`npm install`

Then use:

`npm run dev`

Do not remove `node_modules` between design iterations. Run `npm install` again only when dependencies/package.json change.
